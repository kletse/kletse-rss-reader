No server yet?

Onward has no feeds of its own. A server fetches them around the clock and remembers what you’ve read, and Onward shows you the next article. Here are two ways to get one that don’t involve running a machine yourself.

Neither is free, and Onward has no deal with any of them: nobody here is paid when you sign up.

Hosted Miniflux

$15 a year · 15-day free trial

The least to set up: an account at miniflux.app, and feeds refresh every one to two hours.

The catch comes before you pay: unread articles are removed 60 days after being added, and read ones after 30. That conflicts with working through a backlog, which is what Onward is for. Stop reading for two months and the oldest articles, the ones Onward would have shown you next, are gone. History only goes back 30 days.

To connect: type reader.miniflux.app and sign in. If your account has no password, Onward takes you to the page for an API key instead: Settings → API Keys → Create a new API key.

Onward hasn’t been tried against the hosted service itself yet. It’s the same Miniflux that Onward is tested with, and the trial lets you find out before paying.

Miniflux on PikaPods

From about $1.80 a month · about $22 a year, before any VAT

The same Miniflux in a small server of your own at PikaPods. How long articles stay is up to you, so a backlog can wait.

To connect: type the address of your pod and sign in.

Either way

  • Choose Connect in Onward. The sample articles are still there if you’d like another look first.
  • If you’re leaving another reader, export an OPML file from it and import that in Onward. Otherwise, add your feeds in Onward by their address: press a in the feeds picker.
  • Already have a machine that’s always on? Miniflux and FreshRSS are free to run yourself.

Prices and limits are theirs and can change: these were read from their pages in November 2026.
